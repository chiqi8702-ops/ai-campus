# AI Campus

面向大学生的互动技能学习网页，通过小任务练习 AI 提问、GPT 使用和剪映入门。

本仓库根目录直接存放网页源文件，使用 GitHub Pages 从 main 分支的根目录发布。打开 Pages 设置中提供的网址即可体验，不需要登录 ChatGPT。

## 已开放内容

- AI 提问入门：观察示例、补全要求、独立提问与参考答案。
- 如何使用 GPT：继续追问、核查信息、独立改写。
- 如何使用剪映：8 节目录，前 2 节共 6 个任务可练习。
- 答题动画、阶段纪念、经验及浏览器本地保存。
- 赠送 100 体验币，模拟支付 29 体验币解锁剪映任务包。

支付只用于演示，没有真实扣款。文本反馈是规则检查，不调用 AI API；剪映练习不会操作真实剪映项目。记录保存在各自浏览器中，不跨设备同步。

## 本地预览

用任意静态 HTTP 服务打开本目录即可，不需要安装前端依赖或构建。

## 发布

GitHub 仓库 Settings → Pages → Deploy from a branch，选择 main 和 /(root)。提交网页文件后 GitHub 自动更新网站。
